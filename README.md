# Wander Road

끝없이 이어지는 절차적 생성 도로를 달리는 힐링 드라이브 게임 (three.js, 브라우저에서 바로 실행).

## 실행

빌드 과정이 없습니다. 아무 정적 서버로 폴더를 열면 됩니다.

```bash
npx serve .        # 또는: python3 -m http.server
```

브라우저에서 `http://localhost:3000` (python은 `:8000`) 접속. GitHub Pages에 올려도 그대로 동작합니다.
특정 세계를 다시 보려면 주소 뒤에 `#seed=12345` 를 붙이세요. 세계 유형은 `&type=plains` (plains · hills · alpine · lakes · desert · mixed) 로 고를 수 있고, 시작 화면에서도 선택할 수 있습니다.

도로를 벗어나도 감속이나 경사 저항이 없어서 산 위나 호수 위로도 자유롭게 달릴 수 있습니다.

## 조작

| 키 | 기능 |
|---|---|
| W A S D / 방향키 | 수동 운전 (누르면 자동 주행 해제) |
| Space | 브레이크 |
| E | 자동 주행 켜기/끄기 |
| C | 카메라 전환 (추격 · 보닛 · 시네마틱 · 항공), 마우스 드래그로 둘러보기 |
| T / L | 시간대 변경 / 시간 흐름 |
| P / K / V | 날씨(맑음·구름 조금·흐림·비·폭우·눈) / 차 색상 / 차종 (스포츠카·SUV·트럭·오토바이·배·비행기·여객기·헬리콥터 — 배는 가까운 호수로 이동(R로 다시 찾기), 비행기는 W/S 기수, A/D 선회, Space 감속 · 헬리콥터는 W/S 전후진, A/D 회전, Space 상승, Shift·Q 하강) |
| + / − · 슬라이더 | 목표 속도 20 ~ 4000 km/h (약 200 km/h 이상에선 차가 도로에 고정되어 달림) |
| R / N / H / M | 도로 복귀 / 새 세계 / HUD 숨기기 / 소리 (음악 · 엔진음 · 끔) |

모바일에서는 화면 버튼으로 조작합니다.

## 구성

- `src/terrain-core.js` — 지형/도로 수학 (메인 스레드와 워커가 공유)
- `src/chunk-worker.js` — 지형 조각을 백그라운드 스레드에서 생성 (끊김 방지)
- `src/weather.js` — 비·눈 파티클
- `src/world.js` — 지형(심플렉스 노이즈 + 능선 산맥), 도로 생성(지형 회피·경사 제한·스무딩), 청크 스트리밍/LOD, 나무·바위·풀 배치
- `src/sky.js` — 물리 기반 하늘, 시간대별 태양/달, 지평선 색에 맞춘 안개, 구름, 별, 환경광(IBL)
- `src/car.js` — 차량 모델과 아케이드 주행 물리, 자동 주행(Pure Pursuit + 곡률 기반 감속)
- `src/audio.js` — 합성 엔진음 / 바람 소리
- `src/main.js` — 렌더러, 포스트 프로세싱(블룸·ACES·비네트), 카메라, 입력, HUD
