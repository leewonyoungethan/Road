# Wander Road

끝없이 이어지는 절차적 생성 도로를 달리는 힐링 드라이브 게임 (three.js, 브라우저에서 바로 실행).

## 실행

빌드 과정이 없습니다. 아무 정적 서버로 폴더를 열면 됩니다.

```bash
npx serve .        # 또는: python3 -m http.server
```

브라우저에서 `http://localhost:3000` (python은 `:8000`) 접속. GitHub Pages에 올려도 그대로 동작합니다.
특정 세계를 다시 보려면 주소 뒤에 `#seed=12345` 를 붙이세요.

## 조작

| 키 | 기능 |
|---|---|
| W A S D / 방향키 | 수동 운전 (누르면 자동 주행 해제) |
| Space | 브레이크 |
| E | 자동 주행 켜기/끄기 |
| C | 카메라 전환 (추격 · 보닛 · 시네마틱 · 항공), 마우스 드래그로 둘러보기 |
| T / L | 시간대 변경 / 시간 흐름 |
| P / K | 날씨(구름) / 차 색상 |
| + / − | 자동 주행 속도 |
| R / N / H / M | 도로 복귀 / 새 세계 / HUD 숨기기 / 소리 |

모바일에서는 화면 버튼으로 조작합니다.

## 구성

- `src/world.js` — 지형(심플렉스 노이즈 + 능선 산맥), 도로 생성(지형 회피·경사 제한·스무딩), 청크 스트리밍/LOD, 나무·바위·풀 배치
- `src/sky.js` — 물리 기반 하늘, 시간대별 태양/달, 지평선 색에 맞춘 안개, 구름, 별, 환경광(IBL)
- `src/car.js` — 차량 모델과 아케이드 주행 물리, 자동 주행(Pure Pursuit + 곡률 기반 감속)
- `src/audio.js` — 합성 엔진음 / 바람 소리
- `src/main.js` — 렌더러, 포스트 프로세싱(블룸·ACES·비네트), 카메라, 입력, HUD
